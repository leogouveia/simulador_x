# SIMULADOR X

Projeto para o Hackathon Caixa 2023.
Consiste num App Mobile, feito em Flutter e configurado para ser buildado para Android.

## Como Buildar

Para buildar é nessário desativar o Tree Shaking Icons, visto incompatibilidade com o Tema.

### Buildar para Android:

$ flutter build apk --no-tree-shake-icons
